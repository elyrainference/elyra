# Code of conduct

Be respectful and constructive. Critique code and ideas, not people. Harassment, discrimination, personal attacks and sharing other people's private information are not accepted.

Maintainers may edit or remove comments, commits and issues that break these rules, and may block repeat offenders. Report a conduct problem privately to the maintainers through a GitHub Security Advisory on this repository (choose "other") or by contacting [@Elyrainference](https://x.com/Elyrainference).
