Three ways to use Elyra

  1. Own model · no escrow

    Connect Ollama, LM Studio or an OpenAI-compatible source in your personal node console. Local inference needs no escrow deposit. Hosted API sources still have their own provider bill.

    Set up your node →

  2. Hosted try · free quota

    Try this operator's model in the Playground. A free quota applies; this deployment will tell you if wallet sign-in and a username are required. Signing in is not a payment.

    Open hosted Playground →

  3. Paid peer · escrow session

    Review real seller offers below. Your own node can pay peers in USDG; browser sessions are available only when this deployment enables them. No funds move just by browsing.

What do the labels mean?

Local runs on the seller's own computer. Remote is forwarded to another machine whose owner can read prompts. TEE verified means this node checked a hardware attestation. Clear means no privacy claim. Speed is measured by this node, or claimed by the seller. Select a model to see each seller.

  • Real models, named machines

    Answers come from real models. The route details name the machine that answered, and a value that was not measured says so.

  • Signed receipts

    Each answer from a peer carries a receipt signed with that seller's key: model, tokens, price and amount.

  • Escrow on Robinhood Chain

    Buyers deposit into an escrow contract and sellers redeem signed vouchers from it. Testnet first.

  • Unaudited beta

    The contracts are not audited. Mainnet deposits are capped per wallet (default $20). Only use money you can afford to lose.

Sell capacity

Your model. Your offer. Your earnings.

Selling happens in your own node console, not in this public wallet account. Connect a source, choose models and USDG prices, make the node reachable, then track what buyers actually pay. Start on testnet: contracts are unaudited.

  1. 1

    Connect your source

    Run Ollama, LM Studio or an OpenAI-compatible server. In your own node console, open Sources & tools, detect or add the source, then test it in Playground. Using your own model needs no escrow payment.

    ollama pull llama3.2:1b

    Ollama guide

  2. 2

    Publish a reachable offer

    Open Sell capacity → Models & pricing in your node console. Choose sources, models and prices per million tokens; save the offer. Check Reachability next. A relay lets buyers reach a home node without port forwarding.

    Seller setup · Relay guide

  3. 3

    Track and redeem earnings

    Configure settlement in your node's Payments view and keep ETH for redemption gas. Buyers fund their own escrow; you do not deposit to use your own model. Check Sell capacity → Earnings for served usage, vouchers and paid-out USDG.

    Wallet and USDG · Start your node

What you earn

You set the price

Dollars per million tokens, one default and a price per model if you like. Buyers' routers compare it with every other seller, so a fair price wins requests.

You are paid per token

Each request is metered in tokens and paid with a signed voucher that you redeem from the escrow. No subscription and no minimum.

What it costs you

Your own hardware or API bill, plus a few cents of ETH for gas when you redeem. Your node's panel shows earnings per day.

Example. At $0.05 per 1M tokens, serving 20M tokens pays $1.00. That is arithmetic, not a forecast: what you actually sell depends on your price, speed and model. Elyra is an unaudited beta, so start on the testnet.

The command to run

Linux / macOS shell. Adjust the price and the model server URL.
git clone https://github.com/elyrainference/elyra
cd elyra && npm ci --omit=dev

ELYRA_UPSTREAM_URL=http://127.0.0.1:11434/v1 \
ELYRA_PROVIDE=1 ELYRA_PROVIDE_PRICE=0.05 \
ELYRA_RELAY_URL=https://app.elyrainference.com \
npm start -- --seed https://app.elyrainference.com

Then open http://localhost:8545/app/ on that machine. Review sources, offers, settlement and reachability there. A reachable offer can appear to connected peers; publication does not guarantee buyers or earnings.
